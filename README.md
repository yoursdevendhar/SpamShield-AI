# SpamShield AI

## Overview

SpamShield AI is a web app that checks whether a text message looks like spam. You paste an SMS or email into the page, and the app returns a verdict (Spam or Not Spam) with an estimated confidence score.

The project has three parts:

- **Model:** a scikit-learn pipeline that turns text into TF-IDF features and classifies it with Multinomial Naive Bayes.
- **Backend:** a FastAPI server that loads the trained model and exposes a prediction endpoint.
- **Frontend:** a React app (built with Vite) where users enter a message and see the result.

## Features

- Paste any SMS or email text, up to 5,000 characters
- Instant spam / not-spam verdict with a confidence percentage
- Optional warning message from the API when a prediction is uncertain
- Clear error messages for empty input and for an unreachable API
- Responsive layout that works on phones and desktops
- Keyboard-accessible form with visible focus states

## Getting started

### Prerequisites

- Python 3.9 or newer
- Node.js 18 or newer

### 1. Backend

```bash
cd backend
python -m venv venv

# macOS / Linux
source venv/bin/activate
# Windows
venv\Scripts\activate

pip install -r requirements.txt

# Train the model (only needed once, or when the data changes)
python train.py

# Start the API
uvicorn main:app --reload --port 8000
```

The API will be available at `http://127.0.0.1:8000`. FastAPI's interactive docs are at `http://127.0.0.1:8000/docs`.

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

Open the address Vite prints (usually `http://localhost:5173`).

> The backend must allow requests from the frontend's address. Make sure CORS is enabled in `main.py` for `http://localhost:5173`.

## API reference

### `POST /api/predict`

Classifies a single message.

**Request body**

```json
{
  "message": "Congratulations! You won a free prize. Click here to claim."
}
```

**Successful response (200)**

```json
{
  "prediction": "Spam",
  "confidence": 97.4,
  "warning": null,
  "message": "Congratulations! You won a free prize. Click here to claim."
}
```

| Field        | Type            | Description                                           |
| ------------ | --------------- | ----------------------------------------------------- |
| `prediction` | string          | `"Spam"` or `"Not Spam"`                              |
| `confidence` | number          | Estimated confidence as a percentage                  |
| `warning`    | string or null  | Optional note, for example when confidence is low     |
| `message`    | string          | The message that was analysed                         |

**Error response**

```json
{ "detail": "Prediction failed" }
```

## How it works

1. The text is cleaned and converted into numeric features using **TF-IDF**, which gives more weight to words that are distinctive for a message and less to very common words.
2. A **Multinomial Naive Bayes** classifier estimates the probability that the message is spam based on those features.
3. The API returns the more likely class and its probability as the confidence score.

Naive Bayes is a good fit for short text: it trains in seconds, needs little data, and is easy to explain.

## Limitations

- The confidence score is a model probability, not a guarantee. Naive Bayes tends to be overconfident.
- The model only knows the patterns in its training data. New scam styles, other languages, and heavily obfuscated text may be missed.
- It classifies text only. It does not check links, sender reputation, or attachments.
- Do not use it as the only protection against fraud. Treat results as a hint, not a final decision.
